# Cordeiro Creatives Website

A responsive static marketing website for Cordeiro Creatives.

## Files
- `index.html` — page structure and copy
- `styles.css` — branding, responsive layout, animation
- `script.js` — mobile navigation, reveal animations, form placeholder

## Preview locally
Double-click `index.html`, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing
1. Replace the three portfolio placeholders with real client work.
2. Connect the contact form to Formspree, Netlify Forms, HubSpot, a CRM, or your own API.
3. Add your real email, social links, and business contact details.
4. Add a favicon and social sharing image.
5. Connect Google Analytics / Search Console and Meta Pixel if you want campaign tracking.
6. Confirm all claims and client work are approved for public use.

## Easy hosting options
This site can be deployed as-is on Netlify, Vercel, Cloudflare Pages, GitHub Pages, or most shared hosts.
